# 📊 Student Performance Dashboard

An interactive analytics dashboard built with **Python**, **Pandas**, **Matplotlib**, and **Streamlit**.  
Designed to analyze student grades, generate visuals, export reports, and display insights.

---

## ✨ Features

- Load CSV datasets
- Compute statistics (mean, median, pass rate)
- Generate pie charts, bar charts, line charts
- Export Excel reports
- Export PDF summary using FPDF
- Interactive filtering
- Beautiful Streamlit UI

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- FPDF (PDF Export)
- Hugging Face (Testing) / Streamlit Cloud (Deployment)
